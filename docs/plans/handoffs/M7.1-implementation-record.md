## PR A: authored membership

The implementation uses private map entries retaining their connection index
and exact proposal or retained-definition coordinate. Ordinary nodes and Loop
boundaries call the same binding function. Each distinct selector supplies one
scalar producer; connection order governs the union, map-object key order is
canonicalized, and an explicit destination never silently disappears.

`panel()` emits those maps and requires at least two selector-representable
members. The exact request/result distinction and unique result-typed gather
remain local authoring checks. Admission proves the mapped result seats, not
an unstated request boundary or unrelated outputs.

One private version selector serves preflight and compilation. An exact lock
never consults stable. Counterfactual admission first validates the exact
baseline, then any requested overrides; successful overrides must retain the
source's complete contract hash at every affected exact scope. Baseline
invalidity is `REQUEST_INVALID`; override invalidity is
`COUNTERFACTUAL_LOCK_MISMATCH`. Both use the existing durable rejection law.

`SystemDescription` and its digest domain advance together to 2, publishing
scalar source cardinality separately from ordered mapped-many fan-in. Graph,
manifest, journal, and registry formats remain unchanged. The walker changes
nothing.

## PR A review corrections

The owner relayed an independent exact-head review of `8276581` requesting two
changes. Both corrections use the existing framed map-fault path:

- Distinct maps into a `one` or `optional` destination retain exact coordinates.
  The first conflicting distinct selector owns the fault; evidence also names
  the first selector and its connection index. Repeated identical entries still
  coalesce before choosing that coordinate.
- Selectors missing a port segment regain the base validator's grammar refusal:
  `must be 'node.port' or '$input.port'`. Their repair asks for that segment,
  not a scalar adapter. Well-formed selectors resolving to no source retain
  the separate source-contract refusal.

One private table supplies the map-defect vocabulary, codes, and repairs to
both frame recognition and typed classification. Coordinates still come only
from the shared map-fault writer; no graph, manifest, or public fault code is
added.

Before the fixes, the strengthened focused suite produced 26 failures and 21
passes. Afterward, all 47 cases passed, including inline, Loop, retained, and
retained-inline ownership for both corrections. The isolated mutation inventory
now kills 18/18 mutants: the added checks remove the duplicate's coordinate
frame, point it at the wrong selector, and remove the grammar guard.

Post-correction `uv run verify` passed Ruff, strict mypy, all four import
contracts, and 1,437 tests (21 more than the reviewed head). The owner
independently confirmed those checks, all 18 mutants, and the base compatibility
goldens on `2313552`. Its confirming review was resolved before #23 merged;

The confirming review raised `.port` as a possible malformed selector. That

selector names no source, which is a source-contract refusal, not a grammar
error. General identifier syntax is explicitly unchanged by approved rev 4;
adding a non-empty-node guard would break that promise. The owner independently
reproduced both cases and reclassified the finding as consistent with ADR 0017.

A separate post-merge follow-up pins that distinction through public JSON
admission and a sixth base-manifest fingerprint. The mutation inventory also
tries adding the non-empty-node guard; the compatibility test must reject that
change. No production syntax or validation rule changes in this follow-up.

## PR B: connection endpoints

Implementation base: `b5ff31f362ded8d486e8473a9cb23c2cffba661b`, the exact
reviewed PR A tree squash-merged as #23. The empty-id compatibility follow-up
is a separate first commit; endpoint implementation follows it.

Each graph level checks its connection endpoints against that level's declared
node ids before reachability or node compilation. One invalid connection emits
one `unknown_connection_node` fault, with missing roles ordered `src`, then
`dst`; its source, destination, and connection index remain explicit evidence.
The check collects all endpoint faults at that level, then raises the existing
`AdmissionError` with the accumulated faults. Structural failure unwinds the
attempt before parent binding, Loop finalization, or unused-pin accounting can
mistake uncompiled outputs or scopes for missing ones. As with a cycle refusal,
compilation does not continue through other levels after that structural fault.
The reachability helper has no silent unknown-endpoint branch.

The existing coordinate writer is shared by maps and connections as
`_located_fault`. `_GraphLocation` still names either exact proposal bytes or
one retained definition's bytes. One `_LOCATED_FAULTS` table supplies frame
recognition and typed repairs. There is no extra preflight-only validator,
public fault code, Graph schema, or walker rule.

Endpoint identity is exact string membership, not selector grammar: empty and
dot-containing ids remain legal when declared, while `$input` is a selector
prefix, not an invented connection endpoint. Connection existence and map
resolution are independent obligations; a valid map cannot excuse an absent
endpoint. Neither rule is connector liveness.

## PR B review corrections

The review of `e21fd8c` found that returning `{}` from a failed nested Graph
invented an empty compiled boundary. Parents then emitted missing-source and
Loop faults; the existing public sort could put them ahead of the endpoint
cause and truncate that cause. Lock-aware admission also diagnosed unvisited
pins as unused. The correction is one production branch: raise the existing
admission refusal after collecting the level's endpoint faults. It introduces
no new failure type, state flag, sorting priority, or public contract.

Both endpoint suites now assert the entire returned fault sequence. The
runtime suite also nests each ownership shape under another Graph and a
dependent consumer: the exact endpoint fault survives caps of 1, 2, and 20,
and the consumer is never compiled. Before the correction, the strengthened
runtime suite failed 57 cases and passed 18; the historical control suite failed
14 and passed its three start-refusal cases. Afterward, the focused endpoint,
compatibility, membership, and Loop suite passed all 157 cases.

The original `retained-loop` fixture is a Loop around a reference to a retained
composite. It never exercised a Loop inside that composite; the earlier
ownership claim was incorrect. That fixture and its historical manifest stay
unchanged. A distinct `retained-with-loop` fixture now constructs the missing
shape and pins `body.nodes[0].body.body.connections[1]` in both admission and
counterfactual refusal. A structural test follows that coordinate into the
serialized definition and checks both ownership directions explicitly.

Its seventh historical manifest was captured from the actual `b5ff31f`
validator. The provenance checker reproduces all seven complete manifests and
the empty-node golden; none of the original six fixtures was replaced.
Two separate mutation probes remove the inner Loop's `body` coordinate and

## Retained boundaries

Existing unmapped history is not retrofitted. Reproduce retains that history's
manifest; counterfactual applies current baseline admission and the stronger
complete override-boundary check. M7.1 does not add general connector liveness,
freeze member request boundaries or unrelated outputs in maps, attest runtime
member identity, or add wall-clock human timeouts. Those are not unfinished
pieces of this milestone; the accepted scope deliberately excludes them.
