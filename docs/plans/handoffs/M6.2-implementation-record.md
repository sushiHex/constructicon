## Result

M6.2 closes M6 with one public durable mutation boundary and no new execution
construct, scheduler, persistence schema, or transport authority.

- `ControlPlane` owns the race-safe lifecycle and delegates to exactly two
  private collaborators: `_CommandExecutor` and `_ControlQueries`.
- All ten mutations use strict typed immutable plans and relationally validated
  terminal responses under control schema 3. Response loss at plan commit,
  domain application, and command completion replays one exact fact.
- Committed resume handoffs are recovered by bounded keyset scans. The exact
  attempt transition carrying `resume_command_id` is the receipt; unrelated
  events and advanced baselines cannot revive an attempt.
- Registration and initial promotion are keyed local commands requiring a
  launcher-minted static admin actor. They have no MCP route, and
  `Constructicon` exposes no public mutation or mutable-store bypass.
- Registry snapshots carry coherent
  `RegistryRevision{registration_seq, promotion_seq}` cuts in both memory and
  SQLite. Registry pages and reverse dependencies reconstruct the cursor's
  exact cut rather than current state.
- Cursor schema 2 strictly binds actor, query, bound, and continuation with a
  calibrated corruption checksum. The checksum is not authority.
- Public walker manifest loading and run materialization replace L4 private
  reach-through while leaving the walker the sole graph scheduler.
- Distribution metadata owns the package version. The optional MCP adapter is
  lazy, and a base-only wheel gives concise extra-install guidance without
  hiding transitive import failures.
- The schema-5 SQLite store is decomposed into base, schema, execution,
  registry, control, and query responsibilities. The old `legacy` and `_v5_`
  module names are gone; source-schema migration fixtures are named by their
  real endpoints.

## Compatibility

The SQLite schema and `PRAGMA user_version` remain 5. Existing tables,
constraints, canonical rows, transaction/fence boundaries, and fault seams are
unchanged. Historical command plans and v1/v2 terminal responses replay in
memory without durable rewrites. Cursor and registry-snapshot digest domains are
intentionally new because those contracts changed.

## Failure proof

The implementation adds or strengthens shared memory/SQLite control and
registry contracts; all-ten-operation response-loss and authorization matrices;
bootstrap attestation-to-receipt recovery; lifecycle races; committed-resume
attempt fencing; registry mutation-between-pages; cursor corruption and shape
checks; public/transport structural boundaries; base-wheel optional dependency
behavior; and schema migration/reopen coverage.

Windows gate execution also received two narrow portability corrections found

gate semantics did not change.
